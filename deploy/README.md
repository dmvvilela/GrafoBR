# Cloudflare static hosting

Uses the official `cf` CLI, not Wrangler. The app is exported from Next.js and
served as static assets, with no Worker runtime or paid domain required.

## Build and deploy

```sh
cd web
pnpm install --frozen-lockfile
pnpm test && pnpm typecheck
NEXT_PUBLIC_SITE_URL=https://grafo-br.dmvvilela.workers.dev pnpm build
cd ../deploy
pnpm install --frozen-lockfile
pnpm build
pnpm exec cf deploy --prebuilt --dry-run
pnpm run deploy
```

Authenticate `cf` separately from Wrangler. Deployment requires account read,
Workers read/write, Workers Scripts Write, and Workers Deployments Read.
Do not authorize unrelated scopes.

The current export contains 17,759 assets (free account limit: 20,000), so check
asset counts on every deployment. Do not enable paid upgrades automatically.
Cloudflare clean URLs use drop-trailing-slash and the exported 404 page.

## Cutover safety

Keep the original Vercel deployment working until Cloudflare HTTP and browser
checks pass. Only then deploy a path-preserving redirect on Vercel. Production now redirects via HTTP 308. If validation fails in a future release,
roll back the Cloudflare version before changing the old URL.

GitHub Actions schedules remain disabled. This deployment setup does not enable
paid CI or change data ingestion.


The user accepted that browser-local followed items do not transfer across origins.
Old-origin localStorage is not erased. Vercel remains a minimal server-side 308
redirect preserving paths and query strings; the public domain remains free.

`bash deploy/publish.sh` runs the tests, typecheck, export, canonical normalization,
Cloudflare dry-run and deployment in order. Run only after installing dependencies.
The build fills missing HTML canonical links using the Cloudflare origin; existing
explicit canonicals, verification HTML and 404 pages are not replaced.
Sitemap and robots are generated by Next with the same origin.

No GitHub Actions schedules were enabled and no API token was committed. Future
frontend changes require this local publish script; Vercel Git deployments serve
only the minimal redirect configured in `web/vercel.json`.
